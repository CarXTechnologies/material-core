# Material Core 1.0.3

Расширение для Blender 5.0–5.2 на Windows x64. Шейдер RenderCore входит в комплект.

## Установка и первый запуск

1. Скачайте [Material Core 1.0.3.zip](./Material%20Core%201.0.3.zip). В Blender откройте **Edit → Preferences → Get Extensions → Install from Disk** и выберите архив.
2. В **Add-ons → Material Core** укажите **Texture library / Библиотека текстур**. Выберите корень своей рабочей копии библиотеки, например `E:\SVN\RTC\textures_library`. Индекс и превью готовятся автоматически.
3. Выберите **Window → Material Core**, чтобы открыть каталог в отдельном окне. Для каталога внутри раскладки выберите **Image Editor** в нужной области и нажмите **Material Core** в его заголовке. Встроенный каталог можно сохранить вместе с раскладкой `.blend` или через **File → Defaults → Save Startup File**.
4. В настройках расширения можно выбрать **English** или **Русский** и изменить акцентный цвет. Исходный акцент — `#CD352D`. После добавления, удаления или переименования текстур через SVN Update нажмите **Index / Индексация** в настройках. Готовые обложки переиспользуются.

## Работа с каталогом

- В поиске можно вводить части имени, пути, типа шейдера или тега. Фильтры папок, тегов и коллекций работают вместе.
- В меню **All collections → + Collection** создайте свою подборку. Там же можно открыть **Favorites** и сохранённые подборки. Через **ПКМ → Add to collection** выберите, куда добавить материал. В этом же списке пункт **Remove from …** убирает материал из подборки.
- **ПКМ → To Ignore List** скрывает карточку из каталога, поиска и других коллекций. Выберите **All collections → Ignore List**, чтобы увидеть такие карточки. **ПКМ → Remove from Ignore List** возвращает материал во все его подборки.
- Для поиска только по тегам введите, например, `тег:гранит` или `тег:"карта нормалей"`. Обычный запрос ищет и по названиям, и по тегам. Поиск учитывает **е/ё**, формы русских слов и одиночные опечатки в длинных словах.
- При открытии выбрана папка **Buildings**. Пункт **All folders** показывает все папки. **Ctrl + колесо** меняет размер карточек и сохраняет масштаб в раскладке.
- При наведении на карточку появляются сердечко и значок папки. Сердечко добавляет материал в **Favorites** или убирает его оттуда, а значок папки открывает папку материала в Проводнике. При переключении рабочих областей Blender каталог сохраняет открытый материал, поиск и фильтры.
- Если оставить курсор неподвижным над карточкой примерно на 0,65 секунды, появится увеличенное превью. Движение мыши, прокрутка и нажатие скрывают его.
- Щелчок левой кнопкой открывает страницу материала. Щелчок правой кнопкой открывает меню действий. Внизу страницы находится лента галереи с **Cover**, картами и **3D**. Стрелки и колесо мыши прокручивают ленту. Большая обложка 768 × 768 и карты до 1024 px по длинной стороне готовятся в фоне и остаются в локальном кэше.
- В режиме **3D** перетаскивание в кадре вращает материал, колесо меняет приближение, а **Reset** возвращает исходный ракурс. Можно показать материал на сфере или плоскости. Для 4L кнопка **Layer** переключает слои.
- **Edit tags** открывает редактор внутри Material Core. Введите тег и нажмите **Enter**, выберите подсказку или вставьте теги через запятую. Значок **×** убирает тег. **Save** сохраняет изменения, **Esc** закрывает черновик. Через **ПКМ → Add tag** можно быстро дописать теги.
- **Apply** назначает материал на активный меш в Object Mode. При перетаскивании карточка следует за курсором и плавно уменьшается над подходящим мешем в 3D View. При наличии слотов расширение заменяет активный слот объекта. Если слотов нет, добавляет первый. Один и тот же материал можно назначить на несколько мешей с использованием одного материала Blender. Заменённый материал каталога удаляется, когда у него больше нет пользователей и включённого Fake User. **Ctrl+Z** отменяет назначение, сохраняя каталог открытым.
- **Add to 4L palette** добавляет материал в нижнюю панель. Кнопка **4L palette** в заголовке открывает её для перетаскивания из каталога. Перетащите слой в другой слот для смены порядка или из палитры в каталог для удаления. Кнопка **Name 4L / Имя 4L** задаёт имя материала прямо в палитре. **Apply to selected** назначает 4L с этим именем на активный меш. **Add to collection** предлагает Favorites и пользовательские коллекции, затем запрашивает имя. Сборка в общей коллекции хранится вместе с рецептом слоёв. Для готовых 4L **Load layers into 4L palette** открывает их текущий порядок.
- RenderCore принимает от одного до четырёх выбранных слоёв. Свободные входы повторяют карты первого слоя. Существующая вершинная раскраска меша управляет смешиванием. Расширение её не меняет. Индивидуальные карты Metalness и Emission остаются свойствами исходных материалов, поскольку у 4L нет отдельных входов для них на каждый слой.
- Для готовых SVN-наборов порядок подбирается автоматически. Material Core распознаёт номерные пары карт, распространённые суффиксы и явные признаки 4L или декалей внутри других категорий. В **Edit tags** для готовых 4L можно указать порядок слоёв. Значок **4L** обозначает многослойный материал. **DL** получают декали и материалы с отдельной картой Alpha/Opacity или прозрачными пикселями в Diffuse.

## Локальные и общие данные

- Общие данные автоматически читаются из папки `Material Core` внутри библиотеки. В `tags.json` лежат словарь тегов и назначения материалам, а также заданные имена, типы шейдеров и порядок слоёв. В `collections` каждая подборка хранится в отдельном JSON с именем и списком ID. `ignore-list.json` хранит ID скрытых материалов.
- Добавляйте и коммитьте нужные файлы в обычном SVN. После **SVN Update** открытый Material Core увидит новые, изменённые и удалённые файлы. ID материалов относительны к корню библиотеки, поэтому у каждого пользователя может быть своя буква диска.
- Пользовательская папка Blender хранит индекс, обложки и карты, избранное, локальные рецепты 4L и кэш SVN-авторов. Если общий `tags.json` ещё отсутствует, расширение читает теги из прежнего `.rtc_material_browser/metadata.json`.
- **First SVN upload** показывает автора первого добавления базовой карты. Для запроса откройте материал, затем нажмите **Read / Прочитать** в настройках Material Core. **Cache SVN / Кэш авторов SVN** запрашивает историю библиотеки. Расширение находит установленный SVN-клиент или скачивает официальный клиент при первом запросе с разрешённым **Online Access** в Blender. Для чтения истории нужен доступ к серверу SVN и рабочая авторизация.

## Поддерживаемые материалы

Расширение создаёт материалы в трёх режимах RenderCore — **Diffuse + Roughness + Normal**, **4 Layers** и **Decal Alpha-blend**. Однослойные материалы с прозрачностью используют режим декали, даже если у них есть карты Normal и Roughness. **Decal** берёт прозрачность из Opacity/Alpha или из альфа-канала Diffuse. Для нескольких кандидатов одного канала используется основной файл, соответствующий имени и номеру группы. Созданные материалы включают группу RenderCore из комплекта. Исходные текстуры читаются из рабочей копии, поэтому при обмене `.blend` между компьютерами проверьте доступность путей к текстурам.

Эта сборка проверена на Blender 5.0.1 и 5.2.1 LTS. Фактическая проверка запроса истории рабочего SVN требует `svn.exe` и доступа к серверу.
